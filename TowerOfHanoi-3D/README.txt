Tower of Hanoi 3D - Kids Learning Game
For Ages 8-14 | HTML + CSS + JS | No External Libraries

-------------------
HOW TO PLAY
-------------------
1. Use the slider to choose 3-8 disks
2. Click a disk to SELECT it (gold highlight)
3. Click a peg to MOVE the disk
4. Rules: You CANNOT put a larger disk on a smaller one
5. Win by moving ALL disks to the RIGHT peg (Peg C)
6. Use Auto Solve to see the perfect solution
7. Use Reset to start over

-------------------
JAVASCRIPT ARRAY METHODS USED
-------------------
- forEach(): render disks, loop through pegs
- push(): add disk to a peg stack
- pop(): remove top disk from a peg
- Array.from(): create new disk stack for reset
- length: check stack size for win/validation
